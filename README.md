# R Programming Study

R 프로그래밍 기초 학습 자료와 데이터 분석 실습 파일을 모아 둔 저장소입니다.

## 구성
- `Data/Data/`: GDP, 고용, 과일 등 예제 데이터
- `Data/Note/`: 개발 환경 설정, 변수와 자료형, 벡터 및 데이터프레임, 제어문 등 학습 노트북

## 학습 내용
- R 개발 환경과 기본 문법
- 자료형과 데이터 구조
- 데이터 불러오기 및 다루기

## 실행
R 환경을 준비한 뒤 노트북 및 데이터 파일을 순서대로 확인하세요. 파일별 패키지 요구사항은 각 노트북을 참고해 주세요.
